index.html untuk GitHub

File ini sudah berisi alamat server dashboard-mu. Klik Salin semua, lalu tempel di GitHub (lihat langkah di bawah).

Cara memakainya di GitHub

1. Buka repositori-mu di GitHub, klik Add file → Create new file.
2. Di kolom nama file ketik: index.html (huruf kecil semua).
3. Klik di kotak besar di bawahnya, lalu tempel (Ctrl+V atau Cmd+V). Isinya sangat panjang, jadi tunggu beberapa detik sampai selesai.
4. Klik tombol hijau Commit changes di kanan atas, lalu Commit changes lagi di jendela yang muncul.
